Isolation safeguardsGarde-fous d’isolation
  • Agents never see the rubric (task.json). Any touch: run excluded.Les agents ne voient jamais la grille (task.json). Le moindre accès : passage exclu.
  • One temporary workspace per run, archived and made unreadable once it ends. The parent folder cannot be listed.Un espace temporaire par passage, archivé et rendu illisible à la fin. Le dossier parent n’est pas listable.
  • Claude Code runs bare: no personal instructions, memory, plugins, MCP or web. Loaded configuration recorded for each run.Claude Code tourne nu : ni instructions perso, ni mémoire, ni plugins, ni MCP, ni web. Configuration chargée enregistrée à chaque passage.
  • Every kept transcript audited: no run read another run’s files or any rubric. Incidents found during the day were fixed, killed runs re-run.Chaque transcription gardée a été auditée : aucun passage n’a lu les fichiers d’un autre ni une grille. Les incidents trouvés dans la journée ont été corrigés, les passages tués relancés.

What the method fixes: omissionsCe que la méthode corrige : les oublis

Legora, task 1. Without the method it finds every value discrepancy but misses all four closing deliverables the agreement requires (FIRPTA certificate, Northwind Aerospace consent, title insurance commitment, landlord estoppel). Those four omissions cost 11 of its 12 failed criteria. With the method: all four recovered, 38 / 38.Legora, tâche 1. Sans la méthode, il trouve tous les écarts de valeur mais rate les quatre livrables de closing exigés par le contrat (certificat FIRPTA, consentement Northwind Aerospace, engagement d’assurance titre, attestation du bailleur). Ces quatre oublis coûtent 11 de ses 12 critères ratés. Avec la méthode : les quatre retrouvés, 38 / 38.

The loop: judge, then send backLa boucle : juger, puis renvoyer

Claude Code, task 2. An independent reviewer (Mistral Medium 3.5, no rubric) recomputed every figure by script. Claude Code checked each point, kept the one that held (a total stated as $4.8M whose components sum to $4.9M), set aside three wrong recomputations, and fixed its report in one round: 83 seconds, about $0.42. 48 → 52 / 52 for both judges.Claude Code, tâche 2. Un relecteur indépendant (Mistral Medium 3.5, sans la grille) a recalculé chaque chiffre par script. Claude Code a vérifié chaque point, gardé celui qui tenait (un total annoncé à 4,8 M$ dont les composantes font 4,9 M$), écarté trois recalculs faux, et corrigé son rapport en un tour : 83 secondes, environ 0,42 $. 48 → 52 / 52 pour les deux juges.

When the agent already covers the task, the method adds constraints, not coverage: Claude Code loses one criterion on task 1. For Mistral task 3 with the method, only GPT produced a complete grade (25 / 33); no two-judge gain is claimed.Quand l’agent couvre déjà la tâche, la méthode ajoute des contraintes, pas de la couverture : Claude Code perd un critère sur la tâche 1. Pour Mistral avec la méthode sur la tâche 3, seul GPT fournit une note complète (25 / 33) ; aucun gain confirmé par deux juges n’est revendiqué.

04 / What we don’t claim04 / Ce qu’on ne prétend pas

Read this before quoting us.À lire avant de nous citer.

Not new, and we say soPas nouveau, et on le dit
  • Checking a citation exists and comparing a quote with its source: citators and Westlaw Quick Check already do it.Vérifier qu’une référence existe et comparer une citation à sa source : les citateurs et Westlaw Quick Check le font déjà.
  • Verbatim quotes, adversarial judges, judges from different families: prior research; the official LAB leaderboard already grades with two judges.Citations mot pour mot, juges adverses, juges de familles différentes : travaux existants ; le classement officiel du LAB note déjà avec deux juges.
  • Picking the version in force at the date of the facts, and splitting an answer into claims: done before on French tax law and in FActScore.Choisir la version en vigueur à la date des faits, et découper une réponse en affirmations : déjà fait sur le droit fiscal français et dans FActScore.
LimitsLimites
  • Small n, one run per condition. Three development tasks cannot establish an effect size.Petit n, un seul passage par condition. Trois tâches de mise au point ne suffisent pas à établir un effet.
  • Not comparable to the official leaderboard. Public tasks (possibly seen in training), Claude Code instead of Harvey’s harness, our judges instead of Vals’ API judges.Pas comparable au classement officiel. Tâches publiques (peut-être vues à l’entraînement), Claude Code au lieu du harnais de Harvey, nos juges au lieu des juges API de Vals.
  • Team-written French set, labels proven by script but not yet reviewed by an independent lawyer. 0 false greens on 30 is compatible with a true rate up to about 10%.Jeu français écrit par l’équipe, étiquettes prouvées par script mais pas encore relues par un avocat indépendant. 0 faux vert sur 30 reste compatible avec un vrai taux jusqu’à environ 10 %.
  • Caution has a price. About half of the true French claims come out orange; on ContractNLI, only 13 of 50 true entailments are confirmed.La prudence a un prix. Environ la moitié des vraies affirmations françaises sortent orange ; sur ContractNLI, seules 13 vraies implications sur 50 sont confirmées.
